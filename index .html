Brevet · épreuve d'automatismes

Une interro tirée au sort, corrigée toute seule.

Le professeur crée un sujet et le projette. Les élèves répondent sur la feuille imprimée ou sur leur tablette avec le code du sujet. La tablette corrige et donne un code résultat que le professeur relève.

  1. Le professeur crée le sujet : il obtient un code.
  2. Il projette les questions une par une, avec ou sans minuteur.
  3. Chaque élève saisit ses réponses sur la tablette, ou sur la feuille.
  4. La tablette corrige. Le professeur relève les codes résultat.
